# MedChain — Non-technical Overview

Purpose
- MedChain is a healthcare platform that helps patients, providers, and administrators manage medical appointments, records, prescriptions, and permissioned blockchain-backed audit trails.

Who this is for
- Product managers and stakeholders: high-level features and value.
- Non-technical contributors: documentation, UX, testing, and feedback.

Key features (user-facing)
- Appointment booking and scheduling
- Medical record management and sharing permissions
- Prescription handling and fulfillment
- Audit logs backed by blockchain components (for tamper-evidence)

How to try it locally (non-technical)
1. Ask a developer to run the project locally, or follow the developer guide in `README_TECHNICAL.md`.
2. The app UI runs at `http://localhost:3000` by default once the frontend and backend are running.

How to contribute (non-technical)
- Report issues or feature requests via the repository issue tracker.
- Improve user-facing text and documentation by suggesting edits to this repo.
- Help with manual testing: outline steps to reproduce, expected vs actual behavior, and attach screenshots when possible.
